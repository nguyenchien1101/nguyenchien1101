### 💫 About Me

👋 Hello! I'm **Nguyễn Chiến**, a software engineer and researcher deeply passionate about **Cybersecurity, DevSecOps, Software-Defined Networking (SDN)**, and modern web application development.

* 🚀 **Exploring:** AI-driven threat detection & supply chain security
* 🛡️ **Specializing:** Honeypot environments, malware analysis, cryptography & secure file systems
* 🌐 **Networking:** SDN mobility, host migration & WiFi seamless roaming with Mininet-WiFi & Ryu
* 💻 **Web Tech:** Next.js, TypeScript, Python, REST APIs, and scalable backends
* ⚡ **Fun Fact:** I love building security tools that simulate and analyze complex attacker behavior!
